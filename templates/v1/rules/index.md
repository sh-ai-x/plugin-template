# Rules index

These rules are shared across Claude Code, Codex, and Antigravity. The host pointer files
(`AGENTS.md`, `CLAUDE.md`, and `GEMINI.md`) route into this index instead of duplicating policy.

- `git-workflow.md`: branch, worktree, and review flow
- `skill-authoring.md`: skill naming, frontmatter, and namespace rules
- `session-hygiene.md`: secrets, state, and cache boundaries

When a rule changes, update the referenced file and its tests or documentation in the same change.
